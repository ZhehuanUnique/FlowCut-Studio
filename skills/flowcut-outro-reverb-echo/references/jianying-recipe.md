# 混响回声结尾：音轨结构与剪映配方

## 参考与实测范围

2026-09-20 根据用户提供的结尾录屏核对并在剪映专业版 Windows 11.5.0.14471 实测。录屏主要演示音乐拖尾；实际成片用的是用户素材里的句末人声。参考末尾切到另一教程，不属于本手法。包内不包含参考视频、音乐或用户媒体；下述步骤不依赖它们。

## 信号顺序

```text
原声音轨 ── 短淡出，在收点 C 结束 ──────────────────────┐
尾音种子 + 静音延长 ─ 麦霸 ─ 复合 ─ 延迟回声 ─ 复合 ─ 末端淡出 ─ 混合
```

静音延长必须处于效果处理的输入/复合片段范围内；只把工程总时长拉长，或只给一个到 C 就结束的音频片段加效果，可能把尾音一起截掉。不要把“延长”理解为循环播人声种子，也不默认用时间拉伸。

参考所说的后段“音量调为0”指真正静音/线性音量为零，**不是设为0dB**：0dB是单位增益，不会静音。用静音片段或数字零音频填充，并检查该区间在加效果前确实无声；有静音按钮的轨道不要把整个尾音分支一起静音。

## 原生效果

在声音效果 → 场景音 → 模拟中查找（位置为实测版本，变更后按名称核对）：

1. 尾音分支先加 **麦霸**：**空间大小 100、强弱 100**。
2. 把该效果结果包入复合片段，让下一层处理的是已有混响的声音。
3. 复合片段再加 **延迟回声**：**强度 50**。
4. 再包一层复合片段，在外层的基础音频控制中调尾端淡出及必要的增益。

以上三项参数是录屏可见并在成片中设置过的值；可按内容调整，不是所有素材都应最大混响。实测版本复合片段快捷键为 `Alt+G`，实际执行先核对可见菜单/快捷键，不假定跨版本不变。一个片段可能一次只能选择一个场景音效果，不能直接点第二个覆盖第一个后宣称叠加成功。

## 时间布局

用 `C` 表示原声收点、`L` 表示用于产生回声的末段长度、`R` 表示尾音空间，成片结束 `E=C+R`：

- 原声保持至 C，末端做短淡出，保护最后音节/音乐瞬态。
- 尾音轨与原声对齐；仅在 `[C-L, C]` 放种子，其余是静音。可用长静音容器，也可在局部复合片段内保留长度 R 的静音，再与时间轴对齐。
- 尾音轨应延续到 E，在其末端渐弱，效果处理后确保尾音真的存在。
- 若总时长固定，先在时长预算内找完整句末；没有合适收点则提出调整尾音或征求允许修改的内容范围，而不是截半个词。不得为了给尾音腾空间而擅自删除有效内容。

## 本次人声适配实例（不直接照搬到新素材）

| 项目 | 已验证值 |
| --- | --- |
| 原声收点 C | 11.30s，自然句末停顿 |
| 尾音种子 | 10.40–11.30s，约0.90s |
| 尾音容器 E | 13.00s，即1.70s尾音空间 |
| 原声短淡出 | 11.14–11.30s |
| 种子去突变 | 开头约0.15s淡入；末端约0.04s短淡出 |
| 最外层尾音淡出 | 最后0.70s |
| 画面适配 | 句末帧定格，12.10–13.00s渐黑 |

这不是通用模板强制值：应随语音、拍点、原背景声和目标时长重新定位。音乐版优先保留音乐自然衰减的感觉；人声版检查是否把最后一个词回荡成不自然的重复。

当时实测成片为13秒，完整解码正常；峰值约−1dBFS，11.3秒后音频持续衰减，末0.1秒RMS约−66dBFS。这仅证明该次设置确实产生尾音，新素材必须重新检查，不能引用这些数值冒充当前验收结果。
