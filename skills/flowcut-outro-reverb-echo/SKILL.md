# FC-OUT-001 · Reverb Echo Outro

中文别名：混响回声结尾。

核心是声音延续，而不是把画面硬切黑。独立可用，也可由 `flowcut-editing` 调度。用户本次要求优先于本包预设；只要求分析时不生成改动版。

## 制作

1. 先读 [音轨结构与剪映配方](references/jianying-recipe.md)。确认是独立配乐、人声还是已混合音轨，以及总时长预算。混合音轨应用效果会同时影响人声、音乐和环境声，不能声称已经自动分离。
2. 在独立草稿/副本中工作，保留原片、现有草稿及已完成片头。选完整乐句或完整语句后的自然收点；字幕和静音检测只是线索，不能单靠静音阈值把一个词截断。
3. 分成原声（dry）和尾音效果（wet）两路：只取末段作为尾音种子，让种子后面有真实静音时长，再做混响、复合、延迟回声。不要只拉长显示区域后误以为声音会超出素材边界。
4. 原声在收点附近短淡出，尾音自然接手。控制混合音量，确保既能听到拖尾，又不出现重复起音突兀、啸叫、爆音或数字削波。完整句子优先于机械满足一个预设秒数。
5. 画面继续/定格/淡黑是可选适配，不是参考声音配方的必选项。默认不替用户加标题、Logo、背景音乐；不因加尾音让下一句出现半截字幕。
6. 指定剪映则使用真实可用的原生接口或桌面操控，并遵循对应操控技能。效果缺失、需要付费或工具不可用时说明，不自动购买，也不用软件模拟冒充原生效果。

## 验收与交付

检查最终导出而非只看时间轴：收点后应仍有非零且总体衰减的音频，最后应足够接近静音。对比未加效果版本，防止把原声残留或空白轨当成拖尾。检查峰值、结尾若干短窗口的 RMS、末端是否突断；有听音能力时试听重复字头、尾音与画面收束。

完整解码、确认总时长/画幅/音画同步，验证原片未改变。交付实际成片、独立工程位置、编号、收点和尾音长度，并说明是否用了定格淡出。数值检查不能等同逐段试听，也不保证参考音乐换成人声后听感完全相同。
