# FlowCut Studio

把独立剪辑手法组合成一个成片方案，不把所有效果默认叠到每条视频上。用户本次要求优先于包内预设；仅要求讲解时不动工程。

## 选用手法

先读 [模块目录](references/catalog.json)，按中文名、英文名、稳定编号或技能名匹配。目录中的 `entrypoint` 相对本技能目录解析；只读被选中技能的完整 `SKILL.md` 及其要求的参考资料。每个子技能也能独立运行，不依赖本入口。

- `FC-IN-001`：光圈旋幕开头 / Iris Spin Intro，技能 `flowcut-intro-iris-spin`。
- `FC-OUT-001`：混响回声结尾 / Reverb Echo Outro，技能 `flowcut-outro-reverb-echo`。
- 用户要新手法而目录尚未包含时，说明尚未收录；可以在现有请求范围内分析参考，不冒称已经有对应 Skill。只有用户要求新增/更新技能时才注册它。
- 口播清理可与环境中已有的 FlowCut/口播技能协作，但不随本包复制、重命名或自动执行。用户需要时，先完成内容删剪再定位片头片尾。

## 组合与交接

1. 确认这次的源素材、参考素材、目标时长及是否指定剪映。参考只用于理解手法，成片默认使用用户素材；不把参考视频或音乐混入成片。
2. 保留原片和现有草稿，使用独立工程/副本、不同输出文件名。区分原始素材与已加效果的成片，已有片头不再重复套片头。
3. 先锁定内容剪辑和完整句末/乐句，再为片头分配区间、为片尾预留衰减空间。处理边界冲突后执行，不能靠加速整段或截断句子强塞进时长。
4. 模块之间交接：输入版本、源时间到成片时间映射、总时长、帧率/画幅、字幕类型、可编辑音轨、已生效效果、各模块区间和输出路径。后一个模块接续当前版本，不退回原片覆盖前一个模块。
5. 尽量在同一独立工程中完成、最后一次导出。没有工程而只有成片时可接续处理，但说明不能无损拆掉已烧录的字幕或效果。

## 工具和完成标准

指定剪映时优先用实际可用的剪映接口或桌面操控；有相应操控技能时先遵循其说明。未连接则说明限制，询问是否接受其他方式，不用模拟渲染冒称原生剪映效果。使用其他编辑器时按手法移植并说明差异；本包本身不提供编辑器、会员、浏览器连接或自动下载服务。

导出后检查画幅、帧率、音画同步、效果交接、完整解码、音量峰值与片尾衰减；有听音能力时试听接点。仅做了图像/数值检查时如实说明。不得自动购买效果、发布视频、上传私有素材或同步仓库。

交付可播放成片和独立工程位置，简短列出使用的编号、效果区间、适配改动及未验证项。新增模块时才读 [扩展约定](references/extension-guide.md)。
