# FC-IN-001 · Iris Spin Intro

中文别名：光圈旋幕开头。

从抽象旋幕、眩光过渡到正常画面。独立可用，也可由 `flowcut-editing` 调度。用户本次选择优先于预设；仅问手法时只解释。

## 制作

1. 先读 [已验证配方](references/jianying-recipe.md)。确认源素材、要选的片段、画幅、帧率、字幕及是否已经有片头效果。不要重复叠加已烘焙的片头。
2. 在独立工程或副本中，用用户素材制作。保留原片、原草稿和上一版成片，另命名输出；参考画面和参考音乐不自动成为素材。
3. 根据可读性和节奏安排片头。已验证起点是片头约 3 秒，不是所有素材的固定值。观察首帧、效果最强处与回归正常画面的交接，避免挡住必须看清的脸、产品、文字或动作。
4. 用户指定剪映时使用可用的原生接口/桌面工具，并遵循环境中的操控技能。按配方逐层添加、核对参数和作用区间，确认只影响片头。应用程序版本、窗口位置和效果库可能变化，不复用旧坐标或内部特效 ID。
5. 字幕烧录时不能宣称单独保护字幕图层；效果会一起作用到文字。优先把强效果放在无字区间，或缩短/减弱，并说明适配。仅在用户允许且有干净素材时重做字幕。
6. 保持原有声音；开幕自带声音仅作为可选点缀，不能遮住口播。不能为了复刻参考擅自替换配乐。

## 降级和验收

原生效果缺失、付费或工具断连时说明情况，不自动购买。可以提出免费替代/其他编辑器近似，但只有用户接受后才改变指定执行方式，并明确不是原生同款。

导出后检查实际片头、首个清晰主体、片头结束处、字幕可读性、音画同步和完整解码。避免“应用成功”却导出没有效果、效果覆盖全片、结束处跳一下或附带音效盖过人声。说明使用本模块编号、效果区间、实际参数差异与输出位置。能试听则试听；仅看帧/测量时不声称已试听。
